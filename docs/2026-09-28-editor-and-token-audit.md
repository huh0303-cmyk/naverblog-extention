## 제목 입력 변경

- 스크롤 뒤 위치가 안정되는지 확인하고 제목의 실제 영역 안에서 여러 지점을 확인한다. 줄 끝 한 점이나 화면 경계로 강제 보정한 좌표에 의존하지 않는다.
- 네이버 제목 컴포넌트 선택 상태와 입력 프레임 활성화를 함께 확인한다. 공용 프레임이 활성화됐다는 이유만으로 본문에 제목을 넣지 않는다.
- 제목 선택 검사를 생성 전 preflight에도 연결했다. 입력 불가를 이미지 생성 후 처음 발견하는 낭비를 줄인다. 일반 로그인 상태 확인 때는 매번 제목 포커스를 바꾸지 않는다.
- 실제 페이지 요소에 막힌 경우 감지한 요소와 문서 상태를 알려준다. OS 창이 뒤에 있다는 뜻으로 안내하지 않는다.
- 입력 후 실제 제목 재조회, 기존 제목 보존, 재입력 방지는 유지한다.
- 확장 0.3.11, 편집기 20260928.3. 설치 폴더에 반영했다. 실행 중 확장에는 새로고침이 필요하고, 앱 코드 적용에는 개발 앱 재시작이 필요하다.
