처음 실행 안내

네이버 로그인, 세션 확인, 블로그 발행은 설치된 일반 Chrome의 계정별 창에 확장을 연결해야 작동합니다. Chrome이 없으면 본문 생성은 가능하지만 발행 단계는 진행할 수 없습니다.

  • 로그인은 앱에서 연 계정별 일반 Chrome 창에서만 진행합니다.
  • Blog ID에는 네이버 블로그 주소의 ID를 입력합니다.
  • 계정별 브라우저 연결 코드를 확장에 입력하세요. 한 번 연결한 창의 로그인은 해당 계정에만 유지됩니다.

내 Chrome 연결하기

  1. 계정을 추가한 뒤 ‘블로그 열기’를 누르세요. PC의 정식 Chrome이 해당 블로그 주소로 열립니다. Google 계정 로그인은 필요하지 않습니다.
  2. 설치 폴더 준비를 누르면 영구 설치 폴더가 열리고 경로가 복사됩니다.
  3. Chrome 주소창에 chrome://extensions 입력 → 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드 → 복사한 폴더 선택.
  4. Chrome 확장 아이콘에서 BlogAuto를 열고 아래 연결 코드를 입력하세요. 기존 로그인을 그대로 확인합니다.

계정의 ‘브라우저 연결’을 눌러 주세요.

업데이트 후에는 Chrome 확장 관리 화면에서 BlogAuto의 새로고침 버튼을 누르세요. 최초 설치 후 이 폴더를 이동하거나 삭제하지 마세요.

각 블로그 창의 로그인은 별도 로컬 폴더에 Chrome이 보관합니다. 앱은 쿠키를 읽거나 교체하지 않습니다. 처음에는 계정 창마다 확장을 설치하세요. 이후 세션 만료 시에만 직접 로그인하며 앱은 완료될 때까지 대기합니다.
